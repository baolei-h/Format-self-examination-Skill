# Format Self-Examination Skill
这是《生物活性表面可控构建技术》专著统一撰写规范的自动自查 Skill。

主要用于：
- Word/DOCX 章节格式检查
- 字体、字号、页面和标题层级检查
- 图表编号与图片质量检查
- 参考文献及正文引文检查
- GB/T 7714-2025 参考文献规范检查
- 章节篇幅及结构检查
- 近5–10年研究进展章节检查
- 学术写作与专著结构人工语义检查
- 交稿文件完整性检查

Skill 核心入口为：
`SKILL.md`

可用于支持 Skills/Agent 工作流的环境，也可结合 Codex 等工作模式执行自查。
